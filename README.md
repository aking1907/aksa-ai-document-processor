# AKSA AI Document Processor (v. 24.0.0.0)

**AI-powered sales quote automation for Microsoft Dynamics 365 Business Central**

Uses NLP and OpenAI to interpret customer requests, automatically match products from the ERP catalog, and generate accurate Sales, Purchase, or Service Quotes — dramatically reducing manual effort and errors.

### Current U.S. Pilot
Actively being tested with **America Manufacturing Solutions LLC** (Texas) for secure Human-in-the-Loop AI document-to-quote processing in manufacturing and supply chain.

Built in AL for Microsoft Dynamics 365 Business Central.
